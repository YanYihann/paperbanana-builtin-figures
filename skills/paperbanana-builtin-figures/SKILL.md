# PaperBanana-inspired figures with built-in image generation

Turn manuscript evidence into a figure specification, create appropriate visual assets, and review the actual exports. This adapts PaperBanana's retrieval, planning, styling, visualization, and critique ideas; it is not a run of the PaperBanana software or its multi-agent pipeline. Do not claim otherwise. By default, do not run its runner, call external model APIs, use API keys, download a benchmark, or silently switch to another image provider. The current environment must actually expose a built-in image-generation tool; a ChatGPT subscription alone does not establish that it is available. If unavailable, say so and offer a prompt or await an explicitly authorized alternative.

## Workflow

1. **Retrieve evidence.** Read relevant manuscript sections, captions, data, existing figures, and instructions. Identify source files and roles, claims, relationships, sample units, values, and uncertainty. Separate facts from assumptions and unknowns. Use only authorized materials; do not publish source material or send it to external services unless requested.
2. **Plan.** Match each figure's purpose to its evidence. Specify panel layout, data or asset sources, exact labels, arrow semantics, color/marker mapping, output dimensions, and a checklist of scientific invariants and potential misreadings. For a figure set, keep a consistent visual language and separate plans. Resolve critical missing facts with the user; do not invent them. Match journal requirements when provided or verified.
3. **Style.** Make a concise image prompt with panel hierarchy, components and relationships, exact quoted text, intended use, palette and typography, and explicit constraints. Favor legibility at final size; move dense details to the caption. A reference image is a style or layout reference unless specified otherwise. Preserve any user-designated original image exactly.
4. **Visualize.** For conceptual or illustrative raster figures, call the environment's built-in image-generation tool and follow its current instructions. Pass reference images with clearly identified roles. Inspect the generated image before accepting it. Generated diagrams may misspell labels, invent details, or misplace arrows; treat them as drafts until checked. Use deterministic editing or a code-native/vector workflow for exact labels, connectors, compositing, or editable assets when suitable and permitted. Insert real supplied photographs as real assets, rather than generate substitutes or imply generated samples are evidence.
5. **Plot numerical results separately.** Construct charts from actual data with reproducible local plotting code; do not ask the image model to invent data points, curves, interval geometry, or real specimens. Distinguish units, conditions, missing observations, independent units, and uncertainty types. Retain negative results and intervals crossing zero. If source data are missing, make a clearly labeled empty layout or request the data; do not reconstruct exact points from a summary. For mixed panels, combine verified plots with illustrations and state which components are raster.
6. **Critique and refine.** Compare each export against its evidence and checklist: labels, numbers, arrows, chronology, geometry, image identity, cropping, legend, uncertainty, legibility, overlaps, and unsupported claims. Inspect at full size and intended display size. Iterate targeted corrections and recheck the final export. Record unresolved issues rather than claiming verification that did not occur.
7. **Deliver.** Save the selected output to the requested location or project workspace without overwriting originals. Provide a preview, final prompt and caption where useful, provenance and validation notes, and data/code for quantitative plots. Provide requested formats when feasible. A raster image placed inside a PDF or SVG is still raster; report whether output is native vector, raster, or mixed, and do not claim editable vector output from conversion alone.

Use the available built-in tool rather than an API fallback for ordinary generation. If it cannot produce an exact figure, say what remains unverified and use a supported deterministic workflow where appropriate. Never train, run inference, recompute statistics, or alter original figures merely to create a figure unless the task authorizes it.
